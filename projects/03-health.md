# AI Health Assistant

## Classroom Exercise

**Duration:** 60 Minutes

**Difficulty:** Beginner

**Programming Language:** Python

**LLM:** Groq

---

# Objective

Build an AI-powered Health Assistant that answers general health and wellness questions.

The assistant is intended for educational purposes only and should not diagnose diseases or replace professional medical advice.

---

# Learning Objectives

Students will learn to:

- Accept user input
- Build prompts dynamically
- Call the Groq API
- Display AI-generated responses
- Add safety instructions to prompts

---

# Problem Statement

Develop a Python application that allows users to ask health-related questions.

The application should:

1. Accept a health-related question.
2. Send the question to the Groq LLM.
3. Display:
   - Explanation
   - Possible causes
   - Lifestyle suggestions
   - When to consult a doctor
   - Disclaimer

---

# Example Questions

- What causes headaches?
- What is hypertension?
- How can I improve my sleep?
- What foods contain Vitamin D?
- What is dehydration?

---

# Expected Output

The AI should provide:

- Easy-to-understand explanation
- Possible causes
- Preventive measures
- Healthy lifestyle tips
- Medical disclaimer

---

# Prompt

You are a health educator.

Answer the question in simple language.

Provide:

1. Explanation
2. Possible causes
3. Prevention tips
4. Healthy habits
5. When to consult a doctor

Do not diagnose diseases.
Always recommend consulting a qualified healthcare professional for medical concerns.
