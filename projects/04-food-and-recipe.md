# AI Food and Recipe Assistant

## Classroom Exercise

**Duration:** 60 Minutes

**Difficulty:** Beginner

**Programming Language:** Python

**LLM:** Groq

---

# Objective

Develop an AI assistant that suggests recipes based on ingredients available at home.

---

# Learning Objectives

Students will learn:

- Accept multiple user inputs
- Prompt engineering
- Calling the Groq API
- Generating structured responses

---

# Problem Statement

Build a Recipe Assistant that:

1. Accepts available ingredients.
2. Accepts dietary preference.
3. Accepts cuisine type.
4. Generates a recipe.

---

# Inputs

Ingredients

Example

Tomato
Onion
Rice
Carrot
Peas

Diet

Vegetarian

Cuisine

Indian

---

# Output

The assistant should generate:

- Recipe Name
- Ingredients Used
- Preparation Time
- Cooking Time
- Step-by-step Instructions
- Nutrition Summary
- Serving Suggestions

---

# Prompt

You are an expert chef.

Create a recipe using ONLY the ingredients provided.

If an ingredient is missing,
mention it separately.

Provide:

1. Recipe name
2. Ingredients
3. Cooking steps
4. Preparation time
5. Cooking time
6. Nutrition summary
7. Serving suggestion

---

# Bonus

- Suggest healthier alternatives
- Estimate calories
- Generate shopping list
- Convert recipe into PDF
- Translate recipe
